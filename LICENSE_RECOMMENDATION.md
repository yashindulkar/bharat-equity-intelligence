# License Recommendation — Decision Required

**Status: Open question. No project license is granted by this document.**

The intended private, single-family research use and possible future commercialization conflict with choosing an open-source license prematurely. Data-provider terms can also impose separate restrictions that no code license overrides.

**Proposal:** keep the repository private and all rights reserved until the owner confirms contributor expectations, commercialization intent, patent position, and whether open redistribution is desired. If permissive open source is later chosen, legal review should compare Apache-2.0 (express patent grant) with MIT. Data, fixtures, documentation, trademarks, and third-party assets need explicit, separate notices.

Acceptance: a human-approved decision log entry, exact license text, contributor policy, and confirmation that no bundled dataset violates its terms.
