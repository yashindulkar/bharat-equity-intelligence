# Portfolio Risk and Capital-Protection Review

- Reviewer method: independent subagent run `quant_and_risk`; paired with quantitative review.
- Evidence: complete specification review; no investor profile or portfolio data was available.
- Independence limitation: no separate portfolio-risk reviewer and no suitability validation.

## Principal findings

- Example stock, sector and cash limits are not approved defaults and must not drive personalized
  action without a signed suitability profile.
- Capacity for loss, liquidity needs, debt, emergency fund, household exposures and horizon cannot be
  inferred.
- Use a control hierarchy: legal/suitability, critical data, liquidity, concentration, scenario loss,
  turnover/tax and human review.
- Liquidity must include stressed volume, participation, days to exit, gaps and suspension—not only
  median daily traded value.
- Breaches should block new exposure and trigger review, not automatic liquidation.

Release view: conditional pass; personalized allocation remains a Phase 3 human gate.
