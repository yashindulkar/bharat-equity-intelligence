# Pilot dataset plan

**Proposal, not authorization.** After a provider/product and usage policy pass the gate, request the smallest contract-authorized pilot: a few unmistakably bounded NSE main-board securities spanning a symbol change or delisting, several EOD sessions, one correction, selected supported corporate actions, filing/restatement vintages, historical universe membership, and benchmark TRI observations. Do not ingest the full Nifty 200.

Run mapping, missingness, PIT, identity, action, reconciliation, retention and deletion tests in an isolated local location. Licensed bytes never enter Git or external AI. Exit requires reviewer approval, deletion/retention evidence, deterministic manifests, and zero unresolved critical findings. BSE, rankings, backtests and recommendations remain excluded.
